## Findings

### Architecture delta

**Layering respected across all eight stories.** Presentation (`app/`, `components/`) → services (`lib/services/`) → domain (`lib/domain/`) → DB (`lib/db/`). No `lib/domain/` file imports from `services` or `db` (`grep` 08-27-2026).

- **Source:** import graph check on `champions-app/lib/domain/`; `epic-2-context.md` lines 29–30.

**Schema grew coherently.** `students`, `level_history_entries`, `word_count_matrix_rows`, and wizard timestamp columns on `classes` match the ER diagram intent. `schema.ts` is 82 lines — still manageable.

- **Source:** `champions-app/lib/db/schema.ts`; `git_evidence.py` (6 commits on schema).

**New cross-cutting module:** `lib/revalidation/wizard-affected-paths.ts` centralizes path revalidation after wizard-affecting mutations — good extraction at story 2-8 boundary.

- **Source:** `champions-app/lib/revalidation/wizard-affected-paths.ts:1-14`.
- **Disposition:** accept as-is.

**`neon-http` driver with `db.transaction()` calls.** `reset-class-year.ts`, `replace-word-count-matrix.ts`, and `assign-student-level.ts` all call `db.transaction()`. Driver is `drizzle-orm/neon-http` (`lib/db/index.ts:2-24`). Drizzle batches these over HTTP; true atomicity against concurrent writers is weaker than `neon-serverless` WebSocket transactions.

- **Source:** `lib/db/index.ts:2-24`; `lib/services/reset-class-year.ts:53-98`; `deferred-work.md` lines 56, 99-101.
- **Disposition:** defer — acceptable for MVP class sizes; revisit before Epic 3 concurrent dictation writes or if reset partial-failure is observed in production.
