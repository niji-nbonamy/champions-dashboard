- **Neon driver migration was correctly accelerated** — Epic 2 retro flagged the risk; migration landed before story 3-4 save, avoiding runtime `db.transaction()` failures in production.

- **Promotion infrastructure spans Epic 3→4 cleanly** — domain detection + `pending_promotions` + inline D3/D3+ in Epic 3; dossier D1, Alertes D2, and detection rules 4-5 in Epic 4 read the same records.
