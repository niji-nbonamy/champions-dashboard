### Process lessons

- **Incremental mobile save was the right 5-2 architectural choice** — `saveDictationStudentEntry` avoids forcing partial roster through batch `saveDictation` while reusing the same domain validation and snapshot immutability rules.
- **Story sequencing 5-1 → 5-2 → 5-3 worked** — G2 shell and route guard landed first; B4 form extended the stub; unleveled block was a thin overlay on existing picker/form routes without rework.
- **`epic-5-context.md` breakpoint table prevented tablet/mobile conflation** — 768px G2 gate vs 1024px layout density stayed consistent across three stories.
- **Test volume tracks new surfaces** — 806 tests (+88 from Epic 4's 718) with heavy page-level coverage on mobile routes; fast feedback but no mobile viewport E2E yet.
- **Cross-story spec drift is the epic's documentation risk** — 5-3 changed picker contract that 5-2 spec still describes; `deferred-work.md` caught it but spec was not updated in-session.
