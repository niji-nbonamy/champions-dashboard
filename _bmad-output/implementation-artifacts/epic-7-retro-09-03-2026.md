## Findings

### Architecture delta

**Two independent post-MVP capabilities on existing foundations.** Story 7-1 extends the Epic 1 auth stack (`auth-rate-limit.ts`, `password-hash.ts`, registration validators, middleware policy) with a new `password_reset_tokens` table and Resend transactional email. Stories 7-2/7-3 extend Epic 4 presentation surfaces (`GlobalSuccessCurve`, `presentation-mode.tsx`) without altering scoring or snapshot immutability.

- **Source:** `git_evidence.py`; `epic-7-context.md` lines 7–14, 147–164.
- **Disposition:** accept as-is.

**Password reset isolated as a dedicated service.** `password-reset.ts` owns token lifecycle (generate, hash, invalidate prior tokens, complete reset in transaction). Create/update dictation paths untouched.

- **Source:** `password-reset.ts:48–221`; `spec-7-1` Boundaries lines 22–40.
- **Disposition:** accept — clean separation from registration and login.

- **Source:** `git_evidence.py` per-file net counts; `presentation-mode.tsx` at `ad9eaf4`.
- **Disposition:** accept — appropriate decomposition for dual-panel C3.

**X-axis helpers exported from global curve and reused by category chart.** `category-error-curves.tsx` imports `truncateLabel`, `selectVisibleLabelIndices`, `shouldUseDateLabels`, `getXAxisDisplayLabel` from `global-success-curve.tsx` — enforces X alignment between panels per spec.

- **Source:** `forgot-password/actions.ts:36–41`; `password-reset.ts:122–125` (token deleted on send failure in production).
- **Disposition:** defer — intentional NFR9 trade-off; ops must ensure Resend is configured.

**In-memory rate limiting unchanged from Epic 1.** `auth-rate-limit.ts` uses module-scoped `Map` — same pre-existing pattern now applied to `password-reset` kind; not introduced by Epic 7 but now on a production-critical path.

- **Source:** `auth-rate-limit.ts:10,47–63`; `deferred-work.md` (no Epic 1 retro item closed on this).
- **Disposition:** defer — known serverless limitation.

### Verification gaps (review lenses)

**Sessions not invalidated after password reset.** Auth.js sessions remain valid after `password_hash` update — documented in `deferred-work.md` line 13.

- **Source:** `password-reset.ts:185–221`; `deferred-work.md:11–13`.
- **Disposition:** defer — security hardening post-MVP.

**No rate limit on `/reset-password` submit.** Only forgot-password request is throttled (`password-reset` kind); reset form accepts unlimited attempts.

- **Source:** `reset-password/actions.ts`; `deferred-work.md:14`.
- **Disposition:** defer — not in spec AC; consider for hardening story.

**No automated test for concurrent token consumption.** Transaction uses conditional update (`updatedToken` guard at `password-reset.ts:186–200`) but no parallel-call test.

- **Source:** `password-reset.test.ts` (absence); review lens finding.
- **Disposition:** defer.

**Production email misconfiguration shows success UI.** When `isEmailSendingConfigured()` is false in production, `requestPasswordReset` logs and returns without creating a token (`password-reset.ts:66–74`); action still returns `{ submitted: true }`.

- **Source:** `password-reset.ts:66–74`; `forgot-password/actions.ts:41`.
- **Disposition:** defer — deployment checklist item; README documents Resend setup.

**X-axis label overlap on narrow viewports.** More labels from 7-2 may crowd on small screens — pre-existing SVG responsive limitation.

- **Source:** `deferred-work.md:7–9`; `global-success-curve.tsx:53–60`.
- **Disposition:** defer — acceptable for laptop-primary RDV use case.

**Touch tooltip dismiss asymmetry between global and category curves.** Global curve dismisses on `touchend`; category curves use 2 s timer — UX inconsistency on tablet presentation.

- **Source:** review lens; `category-error-curves.tsx` `CATEGORY_TOUCH_DISMISS_MS` at `ad9eaf4`.

**Schema push reminder.** New `password_reset_tokens` table requires `npm run db:push` before production — not automated in CI (project convention).

### Process lessons

- **Post-MVP epics benefit from strict story independence.** 7-1 (auth) shipped without blocking 7-2/7-3; recommended build order was followed and paid off — X-axis helpers from 7-2 became 7-3's alignment contract.
- **Pre-build ops gates belong in the retro, not only the spec.** Resend DNS was flagged Pending in `epic-7-context.md`; code and docs are ready but production delivery still depends on ops steps the diff cannot verify.
- **Anti-enumeration and genuine failure are indistinguishable in UI by design.** The forgot-password action's always-success contract is correct for NFR9 but requires deployment discipline so teachers are not left stranded.
- **Folder rename after epic delivery creates path drift in artifacts.** The `dossier` → `student-sheet` refactor (`8e7ba5d`) landed after `ad9eaf4`; retros and deferred-work references should be reconciled when docs are next touched.
- **Inherited Epic 6 debt did not block Epic 7** — as predicted in `epic-7-context.md` line 152 — but four open items still accumulate.
