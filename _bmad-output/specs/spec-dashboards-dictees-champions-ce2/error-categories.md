# CHAMPIONS Error Categories

The CHAMPIONS method names its error categories from the method acronym. The class grid has **exactly 9 fixed columns** — one per letter. Categories are not teacher-configurable.

| Letter | Category | What to check |
|---|---|---|
| **C** | Conjugaison | Are verbs correctly conjugated? |
| **H** | Homophones | Homophone confusion (et/est, a/à, son/sont…) |
| **A** | Accords | Agreement within the noun phrase and between subject and verb |
| **M** | Majuscules | Capital letters at sentence start and for proper nouns |
| **P** | Ponctuation | Are periods and commas present? |
| **I** | Illisibilité | Is the handwriting clean and legible? |
| **O** | Orthographe | Are vocabulary words correctly memorized/spelled? |
| **N** | Néant / Non-présent / Non-sens | Are words missing? (absence, omission, nonsense) |
| **S** | Son | Do complex sounds have the correct spelling? |

## Grid implications

- Class-grid entry: one row per student, nine error-count columns (C through S).
- Student dossier dictation table shows raw error counts per category on expand — no per-category % (see `scoring-model.md`).
- Mobile per-student entry: same nine fields, one student at a time.
