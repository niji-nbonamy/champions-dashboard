# MVP Scope

## In scope

| Area | Deliverable |
|---|---|
| Dictation entry | Condensed class grid (C–S columns) + inline promotion **+** on row |
| Dictation lifecycle | Create, save, edit past dictations (see `dictation-lifecycle.md`) |
| Student dossier | Hero curve + collapsed table + « RDV parents » presentation mode |
| Year config | Student roster (CSV) + editable word matrix (F1) |
| Roster management | Mid-year add/remove; departures archived read-only |
| Scoring | Auto global % with snapshot denominators |
| Levels | Promotion via banner, queue, grid indicator, and **+** during entry |
| Mobile | Hybrid per-student entry + quick-tap mode |
| Navigation | Four tabs (laptop) + dictation hub (mobile) |

## Deferred

| Area | Rationale |
|---|---|
| Per-category % and per-category curves on student sheet | Global % and error counts are sufficient; per-category metrics add complexity without meeting the parent-meeting job |
| Full mobile class-grid view | Laptop is primary; per-student mobile entry is the secondary capture path |
| Pixel-perfect paper layout replica | Preserve fill logic only, not visual fidelity |
| Auto pedagogical interpretation for parents | Teacher owns the narrative; app presents facts only |
| Word-count matrix CSV import (F3) | Manual matrix entry sufficient for MVP; format not yet specified |
| Dictation delete / purge | Edit covers correction needs; delete adds data-loss risk |
